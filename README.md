# UE用語タイピング道場

Unreal Engine の開発でよく使う英単語を、意味と紐づけながらタイピングで覚えるためのブラウザ用学習ツールです。



---

## 特徴

- インストール不要。ブラウザだけで動きます
- 収録語数 160 語（UE固有 71 / 共通 89、Lv1〜3）
- 間違えた単語を記録して、次回から優先的に出題します

---

## 2つのモード

| モード | 内容 |
| --- | --- |
| タイピングモード | 日本語の意味を見て、対応する英単語を打つ |
| 4択モード | 英単語を見て、その意味を4つの選択肢から選ぶ |

どちらも **1セット10問** です。

### ミスタイプ制御

先に進ませない方式を採っています。うろ覚えのまま流してしまわないための設計です。

- タイピングモードは1文字ずつ照合し、違うキーは赤いフラッシュとシェイクで弾きます。正しいキーを打つまで確定しません
- 4択モードは誤答のボタンが赤くなって無効化され、正解を選ぶまで次に進めません

### 結果表示

セット終了時に以下を表示します。

- WPM（標準式: 総文字数 ÷ 5 ÷ 経過分）
- 正答率
- ノーミスで打てた問数
- 所要時間
- 間違えた単語の一覧

---

## 苦手リスト

単語IDごとのミス回数を `localStorage`（キー: `ueTypingTerms_weakWords_v1`）に記録します。次回以降はミス回数の多い単語から優先的に出題されます。

- 設定画面のチェックボックスでON/OFFを切り替えられます
- 「苦手リストをリセット」ボタンで記録を消去できます

記録はブラウザごとにローカル保存されます。サーバーには何も送信していません。

---

## 絞り込み

カテゴリ（共通 / UE固有）と難易度（Lv1〜3）で出題範囲を絞れます。

チップは `words.json` の内容から動的に生成しているので、**データ側にカテゴリや難易度を追加すれば、UIにも自動で反映されます。**

---

## 単語データの追加・編集

`words.json` の `words` 配列に、以下の形式で追記してください。

```json
{
  "id": 161,
  "en": "Overlap",
  "ja": "重なり / すり抜けつつ検知",
  "note": "ぶつからずに通過しつつ、重なりだけ検知する状態。",
  "category": "UE固有",
  "level": 1
}
```

| フィールド | 内容 |
| --- | --- |
| `id` | 一意の番号。苦手リストの記録に使うため、既存の値は変更しないでください |
| `en` | 英単語・英語表記 |
| `ja` | 日本語の意味 |
| `note` | 一言解説 |
| `category` | `共通` または `UE固有` |
| `level` | `1`（頻出基礎）/ `2`（中級）/ `3`（応用） |

> **注意:** `index.html` には同じ単語データが内蔵されています（下記フォールバック用）。`words.json` を更新したら、内蔵データ側も同期してください。片方だけ更新すると、環境によって収録語数が食い違います。

---

## 起動方法

`index.html` をダブルクリックすれば開きます。

ただし `file://` で直接開いた場合、ブラウザのセキュリティ制限により `words.json` の読み込みがブロックされることがあります。その場合は画面下部に警告が表示され、`index.html` に内蔵した同内容のデータで自動的に起動します。**単語データが欠けることはありません。**

`words.json` を確実に読ませたい場合は、簡易サーバー経由で開いてください。

```bash
# プロジェクトフォルダで実行
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

VS Code の Live Server 拡張でも同じことができます。
